# 📝 Todo List App

Una aplicación de lista de tareas moderna y funcional con almacenamiento local (Local Storage).

## ✨ Características

- ✅ **Agregar tareas** - Fácil interfaz para crear nuevas tareas
- ✅ **Marcar completadas** - Marca tareas como completadas con un checkbox
- ✅ **Eliminar tareas** - Borra tareas individuales
- ✅ **Filtrar tareas** - Visualiza: Todas, Pendientes o Completadas
- ✅ **Limpiar completadas** - Elimina todas las tareas completadas de una vez
- ✅ **Contador de tareas** - Muestra cuántas tareas pendientes hay
- ✅ **Almacenamiento local** - Los datos se guardan automáticamente en el navegador
- ✅ **Diseño responsivo** - Funciona perfectamente en móviles, tablets y escritorio
- ✅ **Animaciones suaves** - Transiciones visuales agradables

## 🚀 Cómo usar

1. **Descarga o clona el repositorio:**
   ```bash
   git clone https://github.com/daffherrera9-afk/todo-list-app.git
   cd todo-list-app
   ```

2. **Abre el archivo `index.html` en tu navegador:**
   - Simplemente haz doble clic en `index.html`, o
   - Usa un servidor local:
     ```bash
     python -m http.server 8000
     # Luego abre http://localhost:8000 en tu navegador
     ```

3. **Comienza a organizar tus tareas:**
   - Escribe una tarea en el input
   - Presiona "Agregar" o la tecla Enter
   - Marca como completada con el checkbox
   - Elimina tareas que no necesites

## 💾 Almacenamiento Local

La aplicación utiliza el **Local Storage** del navegador para guardar automáticamente todas las tareas. Esto significa que:

- ✅ Los datos persisten incluso después de cerrar el navegador
- ✅ Cada tarea se guarda con su estado de completada/pendiente
- ✅ No se necesita base de datos o servidor
- ✅ Los datos se almacenan de forma segura en tu dispositivo
